🏰 Ogra Boys Hostel - Digital Resident & Management Portal
​A full-featured, mobile-first Web Application for hostel residents and wardens. The system supports night roll call, gate pass approvals, grievance tracking, weekly mess schedules, emergency contact helplines, and central resident directories with real-time cloud synchronization via Google Firebase Firestore.
​🚀 Key Features
​👨‍🎓 Student Dashboard
​Gate Pass Requests: Apply for Day Passes, Overnight/Home passes, or Emergency Hospital leaves with dynamic pass verification codes.
​Night Roll Call Tracking: View personal attendance percentages and historical logs verified by hostel authorities.
​Maintenance & Grievances: Log room maintenance requests (Electrical, Plumbing, WiFi, Carpentry, Sanitation) with live progress tracking and warden remarks.
​Mess Menu Schedule: Daily meal menus (Breakfast, Lunch, Evening Snacks, Dinner) along with weekly schedule inspection.
​Emergency Helplines: Instant dial directory for the Chief Warden Office, Main Gate Guard, Ambulance, Electrician, and Plumber.
​🛡️ Chief Warden Administration
​Master PIN Security: Secure first-time administrator account creation protected by a private master authorization PIN (OGRA@1234).
​Student Admissions Approvals: Approve or decline new room admissions before student dashboard credentials activate.
​Resident Directory: Searchable directory showing resident full names, roll numbers, room numbers, floor levels, join dates, and direct call buttons.
​Night Roll Call Register: Real-time daily roll call tracker with instant single-click batch marking ("Mark All as Present") and individual status toggles (P/A/L).
​Outpass & Gate Verification: Authorize, reject, or mark return completions for student gate passes.
​Live Notice Broadcasting: Broadcast urgent or general hostel notices across student devices in real time.
